# 잉글리시몬 ⚡ (English-mon)

초등학교 1학년 아이를 위한 영어 단어 학습 게임입니다. 파일 하나(`index.html`)로 동작하며, 브라우저에서 바로 실행됩니다.

**▶ 플레이: https://ian939.github.io/english-mon/**

## 게임 방법

1. **단어 퀴즈 / 끝말잇기 / 카드 짝맞추기**로 영어 단어를 맞추면 🪙 코인을 벌어요 (첫 시도 정답 1개 = 1코인, 5콤보마다 보너스)
2. 상점에서 몬스터볼을 사요 — 몬스터볼 🔴 8코인(+30%) · 슈퍼볼 🔵 10코인(+40%) · 하이퍼볼 🟡 15코인(+60%) · 마스터볼 🟣 20코인(+80%)
3. **모험 출발!** 야생 포켓몬(일반/레어/유니크/전설)을 만나 볼을 던져요 — 볼마다 잡을 확률이 표시돼요
4. 잡은 포켓몬은 **도감**에 등록! 한 지역 도감을 다 모으면 **새 탐험 지역이 열려요** (관동 → 성도 → 호연 → … → 팔데아, 1~9세대 1025마리) 👑

## 특징

- 영유~초등 저학년 필수 영어 단어 **1,014개, 20개 카테고리** (모든 단어에 그림 이모지)
- **모드 4종**: 홈 오른쪽 위 버튼으로 👶 아이 → 🧑 부모 → 👩 이모 → 👵 할머니 순환 (코인·볼·도감은 함께 모아요)
  - **부모**: TOEFL(500단어) 또는 IELTS(레벨 1·2·3 × 150단어, 기본 Lv2) 중 선택 · 힌트 없는 하드모드
  - **이모**: 부모와 같은 학습 내용 (가족 톡에서 보낸 사람만 구분돼요)
  - **할머니**: 해외여행 실전 영어 — 여행 단어 450개(Lv1·Lv2·Lv3) + **✈️ 여행 회화 120문장**(듣고 뜻 고르기 · 상황별 문장 만들기). 글자·버튼이 커지고 발음도 더 천천히 나와요
- **🐾 집중 학습 (아이 모드)**: 빠르게 눌러서 정답을 찾는 걸 막고, 틀린 순간에 배우게 해요
  - 문제가 뜨면 잠깐(0.7초) 읽을 시간을 주고 보기가 열려요
  - 틀리면 5초 멈추면서 **내가 고른 보기의 뜻**을 알려주고 다시 들려줘요 (정답은 안 알려줘요)
  - 한 문제에 **3번**까지 — 다 쓰면 정답을 보여주고 넘어간 뒤, 그 단어를 **조금 뒤와 다음 퀴즈 앞부분에 다시 출제**해요 (맞히면 그때 코인 획득)
- **🏆 포켓몬 쇼다운**: 2×3 무대에 피카츄·메타몽·잠만보·이브이·고라파덕 5마리 + 빈자리 1칸. 빈자리 옆 포켓몬을 눌러 밀어서 **순서 카드와 똑같이** 만드는 논리 퍼즐 (보드게임 *Doggy Showdown* 방식)
  - 판마다 목표 최소 이동 수가 늘어나요 (3수 → 6수 → 9수 …, 최대 21수)
  - 클리어 🪙+5, **최소 이동 수로 풀면 +5**(총 10), 거의 최단이면 +2 — 빨리 누르기보다 **생각하기**에 보너스
  - 💡 힌트를 누르면 다음에 밀어야 할 포켓몬을 알려줘요 (그 판의 완벽 보너스는 없어요)
- **도망가기**: 짧은 영어 문장(3~5단어)을 듣고 만들면 도망 성공 — 틀려도 계속 시도할 수 있어요
- **😈 로켓단 조우**: 모험을 이어갈 때 가끔(15%, 7판 안에 확정 — 홈에서 막 출발한 첫 조우에는 나오지 않아요) 로켓단이 그림자 포켓몬을 데리고 나타나요 — 3라운드 퀴즈 배틀로 물리치면 **몬스터볼 없이 포켓몬을 구출**! 실수 없이 이기면 하이퍼볼 보너스
- 영어 발음 자동 재생 (브라우저 TTS)
- 진행 상황 자동 저장 (같은 브라우저에서 이어하기)
- 설치·서버 불필요 — `index.html` 하나로 완결
